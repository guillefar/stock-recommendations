- _2026-07-11 (session 20)_ — **Fundamentals are EQUITY-gated and lean.** `fetch_fundamentals` only runs for `quote_type == "EQUITY"` (mirror of the s18 ETF gate — the index and the 3 untyped tickers get neither block, ETFs keep their composition block), and the user chose the **lean field set** (trailing/forward P/E, dividend yield, net+operating margin, revenue+earnings growth, market cap) over the richer set (debt/equity, P/B, ROE also probed available) to keep token cost negligible. - _2026-07-11 (session 17)_ — **Token trims are prompt-side only; stored data is untouched.** The three HANDOFF_12 levers landed together: (a) the daily-summary prompt receives only the **first sentence** of each recommendation's reasoning (`_first_sentence`, split on sentence-ending punctuation + whitespace) — the full reasoning is still stored per rec and shown on dashboards; (b) the per-ticker schema instruction now asks for "máximo 2 frases" of reasoning (output tokens cost 5× input — the biggest lever); (c) news headlines trimmed 5→3 both at fetch ([src/main.py](src/main.py)) and render ([src/analysis/claude_client.py](src/analysis/claude_client.py)).
